## 3. 上下文配置

| 项                 | 值    |
| ------------------ | ----- |
| `max_model_len`    | 32768 |
| 单次输出上限       | 4096  |
| RoPE 外推方式      | 无 / YaRN factor=... |

**本项不受统一约束，但必须如实声明。**

上下文长度对结果的影响是一阶的，不是可以含糊带过的参数。已有评测记录到：同一推理
模型在 8 K 输出窗口下因截断表现很差，放宽到 16 K 后通过率大幅跳升，而截断样本仅占
5.31%；另一项工作中统一的 4096 输出上限静默截断了七个受评模型中的三个，放宽后有
模型从第五名升至第一。

**基线运行必须使用与方案完全相同的上下文配置**，否则增益项的分子与分母不可比。
